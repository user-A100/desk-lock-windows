# Desk Lock（Windows）

一个面向 Windows 的本地专注工具，结合任务清单、番茄计时、应用白名单、学霸模式、严格模式和定时锁定。

## 已实现

- 本地任务清单、预计时长和一键带入专注
- 15 / 25 / 45 分钟及自定义番茄计时
- 居中的锁定计时器，可选择圆环或翻页时钟，并自定义时间高亮色
- 锁定层底部可低调切换圆环/翻页样式，选择会同步保存
- 锁定层显示当前具体时间和预计结束时间
- 圆环内部只显示倒计时数字，不附加提示文案
- 学霸模式：出现非白名单前台窗口时重新显示全屏锁定层
- 非白名单用户窗口会被自动最小化，进程和未保存数据不会被结束
- 严格模式：退出前强制等待 60 秒并输入恢复短语
- 应用白名单：可直接从“正在运行”或“已安装”列表选择，也保留手动选择 `.exe`
- 白名单应用会验证真实前台窗口并强制激活；Windows 拒绝切换时启动新窗口兜底
- 专注途中修改白名单会立即同步到当前锁定会话
- 专注面板守护条：可一键返回锁定层；离开面板后前台监控会继续拦截
- 每周重复的定时锁定计划，默认使用学霸模式
- 多显示器锁定层、今日/本周统计和本地历史记录
- 单实例运行；重复启动只会唤醒现有窗口，避免多套前台监控冲突
- 可选开机启动

## 安装与运行

```powershell
npm install
npm start
```

运行测试和静态语法检查：

```powershell
npm test
npm run check
```

生成 Windows 安装包：

```powershell
npm run dist
```

## 工作方式与安全边界

本项目不结束、暂停或删除其他进程，也不会替换 Windows 安全锁屏。专注开始后，它通过一个只读的 Win32 前台窗口监控器识别当前应用；不在白名单中的窗口进入前台时，多显示器锁定层会重新出现。这可以避免关闭未保存文档。应用选择面板只列出有可见窗口的运行中应用；未列出的后台程序和系统服务同样不会被结束。

严格模式是自律摩擦，不是防篡改安全边界。具有系统权限的用户仍可通过任务管理器终止程序。定时锁定也要求 Desk Lock 正在运行；建议在设置中启用开机启动。

所有任务、白名单、计划和统计均保存在 Electron 的本机 `userData` 目录，不会上传。

## 目录

- `electron/main.js`：窗口、会话、定时计划和 Windows 拦截协调
- `electron/foreground-monitor.ps1`：只读的前台窗口检测
- `electron/app-catalog.ps1`：只读列出运行中与已安装应用
- `electron/open-allowed-app.ps1`：验证并激活白名单前台窗口
- `electron/minimize-window.ps1`：可恢复地最小化非白名单用户窗口
- 安装包会将上述 `.ps1` 解包到真实文件路径，供 Windows PowerShell 执行
- `src/index.html` / `src/app.js`：主工作台
- `src/lock.html` / `src/lock.js`：全屏锁定层
- `src/core.js`：可测试的状态和时间逻辑
- `tokens.css`：设计令牌
